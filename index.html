Energy Monitor

Energy Monitor is a personal home-automation tool written and used by one person, Carl Hills, for a single household in Belgium. It runs as an add-on inside the owner's own Home Assistant installation.

What it does

Every night it collects the household's solar production, battery, grid import/export, electricity price and weather data, checks the day for problems, and sends a short daily report to the owner. It is used to judge how well the solar panels, home battery and dynamic electricity tariff are working together.

How it uses Google Drive

The tool copies its own data exports (data tables and daily report texts) into a folder in the owner's own Google Drive, so the owner can read them from other devices and analyse them. It uses only the drive.file permission, which limits it to files and folders that the tool itself creates. It cannot see, read or change any other file in the owner's Drive, and it does not read the owner's profile, email address or contacts.

Who can use it

This is not a public product and is not offered to other users. The only Google account that authorises it is the owner's.
