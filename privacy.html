Privacy policy – Energy Monitor

Effective 9 October 2026. Energy Monitor is a personal tool operated by Carl Hills (home page). It is used only by its owner, with the owner's own Google account.

Google user data the tool accesses

When the owner authorises the tool, it requests one Google permission: https://www.googleapis.com/auth/drive.file. With this permission the tool can create, read, update and delete only the files and folders that it created itself in the owner's Google Drive (a single folder of data exports). It cannot access any other file in Drive. The tool does not request or read the owner's name, email address, profile, contacts or any other Google account data.

How the data is used

The files the tool writes contain household energy data (solar production, battery state, grid import and export, electricity prices, weather and the daily report texts). They are written to the owner's Drive only so that the owner can read and analyse them. The data is not used for advertising, profiling or any other purpose.

Storage and security

The Google authorisation token is stored only in the configuration of the owner's own Home Assistant installation, on hardware in the owner's home. It is not sent to any server operated by the developer or any third party, other than to Google to authenticate with the Drive API.

Sharing

The tool does not sell, share, transfer or disclose Google user data to anyone. There is no analytics, tracking or advertising. Any use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Data exports remain in the owner's Drive until the owner deletes them. The owner can revoke the tool's access at any time at myaccount.google.com/permissions and delete the folder from Drive.
